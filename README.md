# Shadow Arena — V6 Artwork Integrated

This build integrates the approved Shadow Arena asset pack into the game.

- 4 distinct character artworks
- 8 weapon artworks
- 8 special-effect artworks
- Character and weapon artwork shown in the selection menu
- Player character artwork rendered in-game
- Weapon artwork follows the mouse aim while the character stays upright
- Special effects use the approved effect artwork
- Existing mobs, 8 specials, sound/music, upgrades and controls retained

Upload `index.html`, `style.css`, `game.js`, and the complete `assets/` folder to GitHub Pages.
