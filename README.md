# Shadow Arena

An endless 2D top-down browser survival game made with HTML Canvas, CSS and JavaScript.

## Controls
- WASD / Arrow keys: move
- Mouse: aim
- Hold left mouse: sword attack
- Space / Shift: dash
- Q: special ability
- Mobile: virtual joystick + buttons

## Run
Open `index.html` locally, or enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → /(root).

No libraries or external assets are required.
